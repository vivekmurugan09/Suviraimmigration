# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

Please report security issues directly to the administrative contact. Do not open public issues for security vulnerabilities.
All reports will be evaluated within 48 hours.

## Best Practices Enforced
- **XSS Prevention**: User inputs (if added) must be sanitized.
- **Dependency Management**: Automated alerts monitor for vulnerable dependencies.
- **Secrets Management**: No API keys or tokens are stored in this static repository.
